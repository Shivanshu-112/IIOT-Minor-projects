# 📊 Excel Data Analysis & Dashboard Project

A practical **Microsoft Excel learning and practice project** covering data entry, formulas, data cleaning, lookup functions, Pivot Tables, charts, and interactive dashboards.

This repository documents my **13-day Excel learning journey**, including hands-on practice with datasets and dashboard creation.

---

## 🚀 Project Overview

The goal of this project is to build a strong foundation in **Microsoft Excel for Data Analysis and Visualization**.

Throughout the project, I practiced:

- Excel fundamentals
- Data entry and formatting
- Excel formulas and functions
- Conditional formulas
- SUMIF & COUNTIF
- VLOOKUP & HLOOKUP
- Dataset handling
- Data cleaning
- Pivot Tables
- Charts and visualization
- Dashboard creation
- Final dashboard development using real-world data

---

## 📅 13-Day Learning Roadmap

| Day | Topic Covered |
|-----|---------------|
| **Day 1** | Introduction to IoT and how it works |
| **Day 2** | Introduction to Microsoft Excel, Excel features, data entry and basic Excel methods |
| **Day 3** | Creating and formatting tables & Conditional Formatting |
| **Day 4** | Basic Excel functions – `SUM`, `AVERAGE`, etc. |
| **Day 5** | Conditional formulas – `IF` and related functions |
| **Day 6** | `SUMIF` and `COUNTIF` formulas |
| **Day 7** | Lookup formulas – `VLOOKUP` and `HLOOKUP` |
| **Day 8** | Downloading datasets from Kaggle and importing them into Excel |
| **Day 9** | Data Cleaning – removing unwanted data and extracting useful information |
| **Day 10** | Creating and formatting Pivot Tables |
| **Day 11** | Creating charts and managing data visualization |
| **Day 12** | Creating and practicing Excel dashboards |
| **Day 13** | Creating the final dashboard using Spotify data |
